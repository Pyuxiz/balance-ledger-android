# 余额手账

一个把银行动账通知整理成余额、账单和桌面小组件的本地 Android 应用。

应用不登录银行账户，不调用银行接口，也不申请网络或短信历史权限。数据只保存在设备本地。它适合快速查看和个人记账，不能替代银行官方流水。

## 功能

- 从已配对银行 App 通知或新到银行短信提取收入、支出、卡尾号、金额和余额。
- 管理多个卡源，按时间查看收入和支出；同一交易的 App 通知、短信通知和短信广播会合并。
- 提供工商银行、中国建设银行、中国农业银行、中国银行、招商银行、交通银行、中国邮政储蓄银行、兴业银行模板。
- 从当前通知列表选择银行 App 或短信 App，自动记录包名。
- 四个桌面小组件入口：2×1、2×2、4×1、4×2，并支持继续缩放。
- 每个小组件独立选择卡源、配色和隐私模式；App 预览与桌面使用同一个位图绘制器。
- Android 8.0 及以上，Material 3 界面，支持系统深色模式。

解析采用以下约束来减少误记：

1. 消息必须来自已配对银行 App，或匹配该卡源配置的短信号码 / 银行落款。
2. 消息必须同时包含卡尾号、收支方向和有效金额。
3. 只有短信通道中明确出现的余额才建立校准点；无余额消息只在已有余额上暂记增减。
4. 卡尾号和来源无法唯一对应时不入账，并在「接收诊断」提示检查配置。

## 使用

1. 在银行 App 中开启消费 / 动账通知，或开通银行短信通知，并允许通知显示完整内容。
2. 添加卡源，选择银行模板并填写四位卡尾号。初始余额可留空，等待带余额的短信校准。
3. 点击「从通知选择银行 App」，从通知栏见过的应用中完成配对。
4. 在「设置 → 权限与接收」开启通知读取。需要原生短信广播时再授予“接收新短信”权限。
5. 把任一尺寸的小组件放到桌面，再到「设置 → 小组件外观」选择对应实例和卡源。

应用不会读取短信数据库，无法恢复已清除的历史短信或通知。部分系统会限制后台通知、小组件刷新或短信广播；可在系统应用详情中按需检查自启动、后台运行与省电设置，无需常驻前台服务。

## 数据与计算

- 金额使用 `Long` 分保存，合计使用 `BigDecimal`。
- App 通知先到时暂记增减；含余额短信到达后建立余额检查点，再重放时间更晚且未校准的交易。
- 新卡余额未知时会记录账单，但不会从零推算余额。
- 账单长期保留；用于短期去重和校准的事件保留 7 天 / 100 条。
- 无年份消息按接收时间推断最近年份，并要求交易时间与接收时间相差不超过 7 天。
- 同分钟、同卡、同方向、同金额、同描述的不同交易可能被保守合并。

## 小组件

小组件只显示当前余额和最近一笔交易。较小尺寸只保留大号余额，空间增加后依次显示交易金额和交易详情。单选一张卡时显示该卡余额，多选时显示已校准卡片的余额合计。

设置页先读取桌面实例提供的真实 dp 画布，再调用与桌面相同的 `WidgetCardRenderer` 生成预览。系统只负责外框、点击与刷新，因此不同桌面的圆角、外边距和更新时机仍可能略有差异。

## 构建

环境：JDK 21、Android SDK 36.1、Gradle 9.4.1。

```powershell
$env:JAVA_HOME='E:\Android_Studio\AS\jbr'
$env:ANDROID_HOME='E:\Android_Studio\SDK'
.\gradlew.bat test assembleDebug assembleDebugAndroidTest --offline --console=plain
```

调试 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。首次构建依赖未缓存时移除 `--offline`。

设备侧绘制测试：

```text
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb shell am instrument -w com.example.icbcbalance.test/com.example.icbcbalance.WidgetRenderInstrumentation
adb uninstall com.example.icbcbalance.test
```

单元测试覆盖多银行脱敏文案、原工行真实格式、金额精度、去重、三种接收通道合并、校准先后顺序、多卡隔离、迁移和小组件实例。设备测试覆盖 64 组尺寸 / 主题 / 配色组合、RemoteViews 承载、余额刷新和逐实例配置持久化。

## 隐私与贡献

Manifest 明确关闭 Android 云备份。通知监听只持久化匹配交易，未配对应用只保留应用名称、包名、出现次数和最近时间供选择，不保存消息正文。

欢迎提交新的脱敏银行文案测试。请用固定虚构尾号和金额替换所有真实信息，不要在 Issue、日志或截图中公开卡号、姓名、余额、商户或完整短信。
